# FAST_PROTOTYPE — режим прототипа без тестов

Owner-решение 2026-10-10 (Oleg): **никаких автоматических тестов в цикле.**

Спеки и пайплайн (`tasks/project.json`, `docs/INDEX.md`) остаются источником правды.
Режем только бесконечные прогоны.

## Правило для всех агентов

- `npm run check` = `tsc --skipLibCheck` + `node --check` на 3 файла. **Тестов нет.**
- `make check` = `bootstrap-check` только. `spec-check` / `transfer-check` / `npm test` — **только вручную**, когда явно скажет Oleg.
- Не гонять `tests/*.test.ts`, `tests_spec/`, `tests_transfer/`, `workers/media` unittest после каждого блока/шага.
- Единственный прогон если нужен — в конце большого куска (`npm run check:all` / `npm run test:manual`) и только по запросу владельца.

Нарушать нельзя — это зацикливает разработку.

## Что осталось для ручной проверки (по требованию)

- `npm run test:manual` — все 70+ тестов
- `npm run check:all` — строгий typecheck + тесты + syntax
- `make spec-check`, `make transfer-check` — только перед релизом

## Вертикаль на сегодня

Собираем рабочий продукт напрямую кодом, без тест-циклов:
**Автономная мастерская (подписки, проекты, генерация) + Windows Компаньон (отдельная программа)** — до конца пайплайна, один проход, один финальный syntax-check.
