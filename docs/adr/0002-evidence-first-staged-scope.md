# ADR 0002: Evidence-first scope и сохранённая полная цель
Статус: proposed; принимается через Q-001.
Контекст: v0.2 объединяет много продуктов, переоценивает control/fallback/сроки, мок-тесты не доказывают видео.
Решение: P0 real bounded experiment → P1 foundation → P2 user loop → P3 repeatability → P4–P6 expansion.
Full feature registry сохранён. Зависимости gates исключают автоматическую массовую разработку без приёмки.
Trade-off: меньше функций в первом релизе, раньше узнаём ограничения и стоимость.
