# Ywoom + JEWEL Core — Spec Pack v0.2

Готовый к реализации пакет спецификаций. Кладётся в корень пустого git-репозитория и отдаётся любому кодинг-агенту (Claude Code, Codex CLI, Cursor, Windsurf, Aider и т.п.).

## Что это
- **Ywoom** — контент-завод: от «хочу канал» до опубликованной серии видео/постов с аналитикой и самоулучшением.
- **JEWEL Core** — минимальный «директор»: оркестрирует агентов-разработчиков и агентов-производства, считает бюджет, ведёт память, решения и журнал. Сначала строит Ywoom, потом им управляет.

## Порядок чтения для агента (строго)
1. `AGENTS.md` — правила работы и экономии контекста (обязательно всегда).
2. `docs/11_ROADMAP.md` — где мы сейчас и что делать.
3. `tasks/BACKLOG.md` — текущая задача.
4. Только те `docs/*`, на которые ссылается задача.

## Как запустить процесс в IDE
1. `git init Ywoom && cd Ywoom`, скопировать пакет в корень, первый коммит.
2. Скопировать `AGENTS.md` также как `CLAUDE.md` (Claude Code читает его автоматически; Codex/Cursor читают `AGENTS.md`).
3. Открыть агента и дать команду: `Прочитай AGENTS.md и выполни следующую задачу из tasks/BACKLOG.md со статусом TODO.`
4. После каждой задачи: агент коммитит, обновляет BACKLOG и `docs/STATE.md`; ты принимаешь/отклоняешь.
5. Раз в этап — независимый аудит второй моделью по `prompts/auditor.md`.

> Рекомендация по экономии: после утверждения концепции прогнать задачу T-000 (перевод spec на английский). Кириллица в токенах в среднем заметно дороже латиницы — на длинной дистанции это десятки процентов экономии.
