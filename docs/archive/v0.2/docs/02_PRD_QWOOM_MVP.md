# 02. PRD — Ywoom MVP

## Пользователи
- **P1 Креатор**: запускает и ведёт канал с нуля. Владелец продукта — первый P1 и проходит весь путь как обычный пользователь, без пресетов и обходов.
- **P2 Командный монтажёр**: загружает исходники → получает Shorts/Reels/Stories.
- **P3 Новичок** (после MVP): «хочу канал, не знаю как».

## Эпики и критерии приёмки

### E1. Аккаунт и рабочее пространство
- Регистрация по email (magic link). Воркспейс с участниками и ролями owner/editor/viewer.
- AC: два пользователя не видят данные друг друга; тест на RLS/авторизацию.

### E2. Онбординг = Channel Launch Interview → Creator Genome
- Единственный путь создания канала. Агент-интервьюер ведёт пользователя по 14 этапам (docs/07): цели, ресурсы, экспертиза, лицо и согласия, аудитория и **язык**, вкус, площадки, стратегия, Bible, персонаж/голос, план, ревью и автономность, бюджет, пилотный эпизод.
- Интервью адаптивное, можно прервать и продолжить; обязательные поля не заполняются сами — только рекомендация + явный выбор.
- Результат: карточка Genome + 3 варианта стратегии канала (формат, частота, тип «лица», прогноз себестоимости).
- AC: Genome сохранён структурно (docs/04), каждое поле имеет источник (confirmed/inferred).
- AC: в коде и сидах нет дефолтных ниш/языков/персонажей (тест-сканер); канал нельзя создать без явно выбранного языка.
- AC: пройден Owner Launch Run (docs/12).

### E3. Проект и Series Bible
- Иерархия: Project → Channel → Series → Episode → Scene → Shot.
- Bible на каждом уровне: персонаж(и), мир, тон, визуальный стиль, запреты, аудитория, шаблон структуры эпизода. Нижний уровень наследует и может переопределять.
- Character Pack: референсы лица/тела/костюмов (генерируются под капотом, утверждаются в чате), голос, манера речи, биография.
- Язык: `content_language` канала обязателен, серия может переопределить (docs/16).
- AC: генерация эпизода в серии B не использует канон серии A (тест на сборку контекста).
- AC: язык эпизода = override серии → язык канала (unit-тест).

### E4. Рабочий чат (Director Chat)
- Чат привязан к уровню иерархии. Команды естественным языком: «сделай 12 эпизодов на месяц», «сделай этот хук жёстче».
- Результаты — интерактивные карточки: план, сценарий, раскадровка, референсы, превью, смета. Кнопки: принять / править / перегенерировать / стоп.
- AC: любое действие чата = типизированная команда в журнале; можно откатить.

### E5. Контент-план и расписание
- План на N эпизодов: темы, хуки, форматы (Short / Long 9+ мин / Carousel), даты, смета.
- После утверждения — автозапуск производства по расписанию; режим ревью: «проверять всё» / «проверять только отклонения QA» / «без проверки».
- AC: план останавливается/редактируется без потери готовых эпизодов.

### E6. Производство (docs/05)
- Сценарий → раскадровка → cost tiers → генерация ассетов → озвучка/музыка/SFX → монтаж → субтитры → обложка → QA → пакет публикации.
- AC: эпизод воспроизводим по записи (все промпты, seeds, модели, версии сохранены).

### E7. Автомонтаж исходников (для P2)
- Загрузка сырых видео → транскрипция → выбор лучших моментов → вертикальный рефрейм с трекингом лица → субтитры с анимацией → B-roll/зумы/переходы/SFX → экспорт 9:16.
- AC: 10-минутный исходник → 3–5 клипов 30–60 с без ручных правок, приемлемые по QA.

### E8. Медиатека
- Все ассеты с тегами, фильтры по проекту/серии/площадке/статусу, версии, «эталон» флажком.
- Хранение по стратегии docs/03 §Storage.

### E9. Публикация
- YouTube: загрузка через официальное API (заголовок, описание, теги, обложка, плейлист, отметка о синтетическом контенте, расписание).
- Instagram/TikTok: MVP — пакет для ручной публикации (файл + текст + хэштеги + напоминание); API — после прохождения ревью площадок.
- Метаданные и субтитры — на языке эпизода и выбранных дополнительных языках (docs/16).
- AC: публикация идемпотентна (повтор не создаёт дубль).

### E10. Аналитика и обратная связь
- Импорт метрик YouTube Analytics по видео ежедневно: просмотры, CTR, AVD, удержание по секундам, подписки.
- Разбор эпизода: какие хуки/сцены удержали, что провалилось → гипотезы → предложения в план.
- AC: каждое предложение ссылается на данные.

### E11. Бюджет и расходы
- Смета до запуска, факт после. Лимиты на проект/месяц/эпизод. Превышение → пауза + запрос.
- Посекундный Cost Ledger: сгенерировано / оставлено секунд, waste_ratio, cache_hit_rate Director LLM (docs/10).

### E12. Studio (docs/15)
- Экраны Cinema / Effects / Characters / Edit / Lipsync / Apps + доступ к каждому навыку из Director Chat.
- AC: каждый пресет камеры имеет фолбэк-реализацию без платных вызовов; каждый навык имеет evals и выдаёт delivery report.

### E13. Языки и локализация (docs/16)
- Выбор языка на канал, override на серию, режимы single / subtitled / dubbed / mirror_channels.
- AC: эпизод на выбранном языке проходит language-QA (docs/16 §QA).

## Вне MVP
Платные подписки, маркетплейс шаблонов, мобильное приложение, собственные модели, прямой постинг в TikTok до аудита.
