# 05. Производственный конвейер

Каждый шаг — идемпотентная функция `step(manifest) → manifest'` с QA-гейтом. Сбой → ретрай шага, а не всего эпизода.

## Съёмочная группа (роли-агенты, вызываются по необходимости)
Showrunner (стратегия серии) · Writer (сценарий, хуки) · Director (раскадровка, ритм) · DOP (камера, свет, ракурсы) · Costume/Art (внешность, локации, консистентность) · Sound (голос, музыка, SFX) · Editor (монтаж, субтитры, переходы) · Packager (заголовок, обложка, описание) · QA Critic (проверка).
Роль = промпт + инструменты + модель из роутера. Это не 9 постоянно работающих агентов, а 9 конфигов.

## Director и навыки
Всеми ролями дирижирует **Director LLM** (docs/06 §Director). Он не генерирует медиа сам: планирует и вызывает навыки студии (docs/15), а те — видео-API, Blender и FFmpeg. Шаги 3–8 реализуются набором навыков.

## Язык
Язык эпизода фиксируется в манифесте на шаге Brief (override серии → язык канала). Дубляж и субтитры на других языках — отдельный шаг **Localize** после Edit (docs/16).

## Шаги
1. **Brief** — из Bible + плана + трендов + инсайтов прошлых эпизодов собирается бриф (минимальный контекст: только релевантный канон).
2. **Script** — сценарий с таймкодами, хук первые 1–3 с (Shorts) / первые 30 с (Long), удержание по структуре серии. 2–3 варианта хука → QA выбирает.
3. **Storyboard** — сцены и шоты: описание, камера, длительность, персонажи, локация, эмоция. Каждой сцене присваивается **tier**:
   - T0: изображение + движение камеры (Ken Burns, zoom/pan) — копейки
   - T1: 2.5D-параллакс, моушн-графика, текст, инфографика
   - T2: Blender — блокинг камеры/объектов → рендер или как control для генерации
   - T3: image-to-video (стандартная модель)
   - T4: премиум-модель — только ключевые кадры (хук, кульминация)
   Доля T3+T4 — настройка канала (`ai_video_share_max`), задаётся в онбординге по рекомендации системы из бюджета. Каждому шоту также назначаются пресет камеры, жанровая логика и эмоция (docs/15).
4. **Reference** — генерация/подбор ключевых кадров с Character Pack (консистентность лица/костюма). Утверждение в чате или авто при review_mode=off.
5. **Motion** — генерация видео шотов через роутер. Отказ фильтра → шаг **Safety Rephrase**: переформулировка ложных срабатываний (напр., «взрыв энергии» ≠ насилие). Реальный запрещённый контент не обходится — сцена помечается и заменяется альтернативой.
6. **Audio** — TTS голосом персонажа/клона, музыка (лицензионно-чистая: генерация или библиотека с лицензией), SFX, микс с ducking.
7. **Edit** — сборка Timeline JSON: склейка, J/L-cut, переходы, зумы, субтитры (караоке-анимация), звуковые акценты, цветокор-LUT серии.
7b. **Localize** — субтитры/дубляж/метаданные на дополнительных языках по `localization_mode` (docs/16). Пропускается при `single`.
8. **Package** — 3 варианта заголовка, 2–3 обложки, описание, главы (Long), теги, метка AI-контента.
9. **QA** — автоматические проверки (docs/12) + LLM/VLM-критик по чек-листу серии. Оценка < порога → точечная перегенерация шота (макс. 2), дальше — ревью человека.
10. **Review** — по режиму. Правки человека фиксируются как обучающие данные.
11. **Publish** — по расписанию, идемпотентно.
12. **Learn** — через 48 ч и 7 дней: метрики → разбор → инсайты/эталоны/эксперименты.

## Длинные видео (9+ мин)
Структура из «блоков» по 60–120 с с мини-хуками; большая доля T0–T2 и голос как несущая часть; главы; mid-roll-точки.

## Карусели и посты
Тот же конвейер без Motion: Script → слайды → изображения/типографика → экспорт PNG + текст.
