# 07. Creator Genome и Expert Amplifier

## Creator Genome — цифровая модель креатора
Одна структура на человека. Из неё строятся стратегия, «лица» канала и стиль подачи.

| Блок | Примеры полей |
|---|---|
| Цели | доход/мес, срок, слава vs анонимность, личный бренд vs медиа-актив |
| Ресурсы | часов в неделю, бюджет на генерации, оборудование, команда |
| Экспертиза | темы, глубина (1–5), доказательства (опыт, кейсы), уникальные истории |
| Подача | лицо в кадре (да/нет/двойник), голос (свой/клон/синтез), язык, темп, юмор |
| Вкус | любимые каналы, визуальные референсы, «никогда не делать» |
| Аудитория | для кого, их боль/желание, уровень |
| Решения | история выборов владельца (из `decisions`) |

Каждый факт: `tier` (confirmed / inferred / experimental), `confidence`, контекст, дата. Выведенное системой никогда не становится confirmed без подтверждения. Устаревает по `valid_to`.

## Типы «лица» канала (из одного Genome)
1. **Self** — сам человек; Ywoom монтирует, пишет, упаковывает.
2. **Twin** — цифровой двойник (лицо/голос) только с явным документированным согласием владельца лица; обязательна метка AI.
3. **Persona** — вымышленный персонаж с Character Pack и биографией (создаётся в онбординге, готовых персонажей «по умолчанию» нет).
4. **Faceless** — голос + визуал.
Один проект может сочетать типы в разных сериях.

## Strategy Engine
Вход: Genome + ниша + данные площадки. Выход: 3 стратегии с разной ставкой (быстро/дёшево, баланс, амбициозно): формат, частота, tier-микс, себестоимость/мес, реалистичный горизонт роста, риски. Новичок выбирает — система делает остальное.

## Expert Amplifier
Для эксперта с ценным знанием, но слабой подачей.
1. **Knowledge Extraction** — агент-интервьюер (голос/чат) вытягивает знания, кейсы, мнения → база знаний эксперта.
2. **Value Check** — оценка полезности: уникальность vs уже существующий контент, спрос (поисковые запросы/комментарии). Честный вердикт: проблема в подаче или в пользе.
3. **Packaging** — упаковка в форматы под его ресурсы (например, 15 мин записи голоса в неделю → 3 Shorts + 1 Long).
4. **Coaching Loop** — после каждого выпуска: что улучшить в подаче (1–2 пункта, не 20).

## Адаптация под пользователя
Сложность интерфейса и глубина объяснений зависят от уровня пользователя (novice/pro). Новичок видит «Готово к публикации? Да/Нет», профи — таймлайн и tier каждой сцены.

## Channel Launch Interview (онбординг от А до Я) — v0.2
Единственный путь запуска канала для всех, включая владельца. Реализуется как машина состояний (`onboarding_sessions`): можно прерваться, вернуться, переиграть этап.
| # | Этап | Обязательный результат |
|---|---|---|
| 1 | Цели | цель, срок, метрика успеха |
| 2 | Ресурсы | часов/нед, оборудование, команда |
| 3 | Экспертиза | темы, глубина, истории (Knowledge Extraction при необходимости) |
| 4 | Лицо и согласия | тип лица (Self/Twin/Persona/Faceless), согласия на лицо/голос |
| 5 | Аудитория и язык | сегмент, рынок, **content_language** + режим локализации (docs/16) |
| 6 | Вкус | референсы, «никогда не делать» |
| 7 | Площадки | подключение аккаунтов (OAuth) или ручной режим |
| 8 | Стратегия | выбор из 3 вариантов Strategy Engine со сметой |
| 9 | Bible | черновик канона канала и первой серии, утверждён |
| 10 | Персонаж и голос | Character Pack / identity / голос, утверждены |
| 11 | План | контент-план и расписание |
| 12 | Контроль | review_mode, уровень автономности |
| 13 | Бюджет и хранилище | лимиты, доля AI-видео, куда хранить |
| 14 | Пилот | пилотный эпизод, оценка и правки → запуск конвейера |
Правила:
- Каждый этап: вопросы → рекомендация с обоснованием (и стоимостью, если влияет) → явное подтверждение. Никакой предвыбранной ниши или языка.
- Глубина адаптивна: новичку — простые вопросы и объяснения, профи — быстрый проход.
- Каждый ответ — факт Genome с tier. Метрики трения (время, возвраты, «непонятно») пишутся в `friction` и питают улучшения самого интервью.
