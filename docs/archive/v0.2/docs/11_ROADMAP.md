# 11. Дорожная карта

Сроки — ориентир при ~1–2 ч/день участия владельца. Здесь нет этапа «настроить первый канал»: канал владельца создаётся только через онбординг.

## M0 — Фундамент (нед. 1)
Monorepo, docker compose, Postgres+pgvector, миграции, auth magic link, CI (lint/type/test), `make check`, contracts-пакет, Command Journal, STATE.md.
**DoD:** зелёный CI; регистрация и вход; изоляция workspace покрыта тестом.

## M1 — Мозг и иерархия (нед. 2–3)
Project/Series/Episode/Bible CRUD с наследованием, языковая модель (docs/16), Genome + Channel Launch Interview (этапы 1–13, без дефолтов), Director LLM-адаптер с prompt caching, Director Chat (команды → журнал), Model Router с mock-адаптерами + 1 LLM-адаптер, бюджет-сметы.
**DoD:** новый пользователь проходит интервью и получает канал (с выбранным языком), серию и план 10 эпизодов со сметой; всё в журнале, откат работает; E2E на 3 разных фикстурных персонах (разные ниши и языки).

## M2 — Конвейер на моках (нед. 4–5)
Skill Runtime + первые пресеты камеры в 2.5D (docs/15), Cost Ledger; весь pipeline docs/05 на mock-провайдерах; Timeline JSON → FFmpeg рендер реального MP4 (T0/T1 сцены без платных вызовов: изображения-заглушки, TTS-мок, субтитры).
**DoD:** `make eval` собирает 3 эпизода из фикстур в MP4; каждый шаг ретраится независимо.

## M3 — Реальные модели + Owner Launch Run (нед. 6–8)
Прямые API: изображение, 2–3 видео-модели (по итогам Benchmark Suite, D11), TTS, музыка/SFX, ASR, VLM-критик. Studio: риг, prompt-реализации пресетов, Character Pack, Storyboard Lock, мульти-шот. QA-гейты. Публикация на YouTube. Медиатека. Этап 14 интервью (пилот).
**DoD:** владелец прошёл Owner Launch Run как обычный пользователь (docs/12); 3 эпизода его канала опубликованы; посекундная себестоимость и waste_ratio посчитаны.

## M4 — Обучение (нед. 9–11)
Импорт аналитики, разбор эпизодов, инсайты, Golden Library, эксперименты с заголовками/обложками, генерация кэш. Автомонтаж исходников (E7). Blender-воркер (T2) + Blender-реализации пресетов. Lipsync Studio, апскейл, VFX-пресеты, Apps. Локализация (субтитры + дубляж).
**DoD:** 20+ эпизодов; acceptance rate и стоимость минуты отслеживаются; ≥ 1 эксперимент завершён автоматически.

## M5 — JEWEL Ops Director (нед. 12–14)
Мониторинг, авто-создание задач, Dev Stack в CI на staging, Model Scout + Benchmark Suite, Skill Lab (самоулучшение навыков), Trend Harvester.
**DoD:** JEWEL сам нашёл и починил ≥ 1 дефект через ветку+CI; предложил ≥ 1 замену модели с бенчмарком.

## M6 — Бета для внешних пользователей
Онбординг новичка ≤ 60 мин, шаблоны серий, лимиты/тарифы, биллинг (позже).
**DoD:** 5 внешних пользователей опубликовали первое видео без помощи.
