# 12. Качество и тесты

## Пирамида
1. **Unit** — домен, наследование Bible, сметы, политики (100% для policy/budget).
2. **Contract** — каждый адаптер на записанных ответах; контракты между модулями (zod).
3. **Integration** — API + БД + очередь (testcontainers).
4. **Pipeline eval** — `make eval`: фикстурные эпизоды → MP4 → автопроверки. Регрессия, если метрики хуже baseline.
5. **E2E** — Playwright: онбординг → план → эпизод → публикация (в mock-режиме).
6. **Security** — изоляция workspace, секреты, права агентов, prompt-injection в пользовательском вводе.

## Автоматический QA медиа
- Технический: длительность, разрешение, fps, битрейт, громкость (LUFS-цель), тишина/клиппинг, чёрные кадры, рассинхрон субтитров.
- Контентный (VLM/LLM-критик по чек-листу серии): консистентность персонажа, артефакты (руки, лица, текст), соответствие сценарию, читаемость субтитров, сила хука, соответствие Bible и запретам.
- Площадочный: формат, длина, метка AI, запрещённые элементы.

## Правила
- Платные вызовы в CI запрещены.
- Любой баг → сначала падающий тест, потом фикс.
- Flaky-тест = баг с приоритетом.
- Порог покрытия не цель; цель — покрытие критериев приёмки.

## Owner Launch Run (догфудинг как обычный пользователь) — v0.2
Приёмочный тест M3, который проходит сам владелец.
- Чистый аккаунт с ролью owner без админ-флагов; флаги `owner_bypass`/сиды канала запрещены (проверяется тестом).
- Проход всех 14 этапов интервью через UI/чат, пилотный эпизод, публикация.
- Итог: отчёт трения (время на этап, возвраты, места, где пришлось писать агенту вне процесса) → задачи в BACKLOG.
- Автоматический двойник: Playwright-E2E с LLM-«синтетическим пользователем» на ≥ 3 разных персонах (разные ниши, языки, типы лица) в mock-режиме — в каждом CI.

## Тесты v0.2
- **No-defaults scanner**: статический тест — в `apps/`, `packages/`, миграциях и сидах нет захардкоженных языков контента, ниш и персонажей (исключение — `fixtures/`).
- **Language QA** (docs/16 §QA) в pipeline eval.
- **Skill evals**: у каждого навыка golden-набор на моках в CI; регрессия блокирует продвижение версии canary → active.
- **Cost Ledger**: сумма строк = факт эпизода; смета и факт расходятся ≤ 20% на фикстурах.
