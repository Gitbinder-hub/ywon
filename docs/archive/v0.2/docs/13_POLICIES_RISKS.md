# 13. Площадки, монетизация, риски

> Правила площадок меняются. Перед M3 и далее ежемесячно Scout сверяет актуальные правила и обновляет этот файл.

## YouTube (ключевое для дохода)
- **Монетизация и «неаутентичный»/шаблонный контент.** Массовый однотипный контент рискует не пройти YPP или потерять монетизацию. Отсюда требования к Ywoom: сквозной сюжет и персонаж, реальная ценность, вариативность структуры, без конвейерных клонов. QA проверяет «похожесть» эпизодов между собой.
- **Раскрытие синтетического контента.** Реалистичный AI-контент требует отметки при загрузке. Ywoom ставит её автоматически.
- **API-загрузка.** У непроверенных API-проектов загруженные видео могут быть ограничены приватным режимом до прохождения аудита Google — запланировать аудит заранее (задача в M3). Суточная квота API ограничена — учитывать в планировщике.
- **Музыка.** Только лицензионно-чистая, иначе Content ID.

## Instagram / TikTok
- Автопубликация — через официальные API после прохождения ревью приложений; до этого — пакет для ручной публикации.

## Фильтры моделей
- Safety Rephrase — только для ложных срабатываний. Не обходить политики: реальные люди без согласия, насилие/сексуальный контент, товарные знаки, дезинформация. Отказ фиксируется, сцена заменяется.

## Двойники и голоса
- Клонирование лица/голоса — только собственных или с письменным согласием, хранится в `consents`.

## Риски проекта и меры
| Риск | Мера |
|---|---|
| Рост цен/закрытие API | роутер, fallback, open-weight уровень |
| Демонетизация | качество, уникальность, метка AI, контроль похожести |
| Взрыв расходов | сметы, лимиты, tier-микс, kill switch |
| «Красивая система, которая не решает задачу» | dogfooding с M3, North Star метрики |
| Агенты ломают ядро | защищённые зоны, CI, staging, откат |
| Ожидание «100% дохода» | доход не гарантируется ничем; система максимизирует число и качество попыток и скорость обучения |

## Дополнения v0.2
- **Сторонние платформы и навыки**: изучаем публичные функции и паттерны; не копируем проприетарные промпты, ассеты и бренды. MIT-код — только с соблюдением лицензии.
- **Условия видео-API**: у каждого вендора проверяем права на коммерческое использование результата, региональные ограничения и риск закрытия модели (пример: сообщения об удалении Sora 2 из API). Риск покрывается fallback-цепочками.
- **Локализация**: метка AI и требования площадки соблюдаются на каждом языке; клон голоса для дубляжа — только с согласием владельца голоса.
