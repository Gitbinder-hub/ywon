# 14. Решения владельца

## Закон «Нет продуктовых дефолтов»
Ywoom строится сразу как массовый продукт. Ничего не настраивается под «первый канал владельца».
- Ниша, «лицо», язык, форматы, частота, бюджет, режим ревью, уровень автономности, хранилище — **выбирает пользователь в онбординге** (docs/07 §Channel Launch Interview).
- Система может рекомендовать с обоснованием, но обязательные поля требуют явного ответа.
- В коде, сидах и миграциях запрещены захардкоженные ниши, персонажи и языки контента. Фикстуры для тестов — разнообразные (несколько ниш, языков, типов лица) и лежат только в `fixtures/`.
- Владелец запускает свой канал как обычный пользователь, без админских обходов (docs/12 §Owner Launch Run).

Значения инженерных параметров (таймауты, пороги QA, число ретраев) — не продуктовые дефолты; они живут в `config/` и меняются без кода.
