# 16. Языки и локализация

## Принцип
В системе **нет языка контента по умолчанию**. Язык выбирает пользователь для каждого канала. Система может рекомендовать язык с обоснованием (аудитория, рынок, CPM, конкуренция), но не выбирает сама.

## Уровни
| Уровень | Поле | Правило |
|---|---|---|
| Аккаунт | `users.ui_language` | язык интерфейса и Director Chat; не влияет на контент |
| Канал | `channels.content_language` (BCP-47, напр. `ru`, `en-US`, `es-MX`) | **обязателен** при создании канала; без него канал не создаётся |
| Серия | `series.language_override` | опционально; для каналов, где разные серии на разных языках |
| Эпизод | `episodes.language` | вычисляется: override серии → язык канала; фиксируется в манифесте |

## Режимы мультиязычности канала (`channels.localization_mode`)
1. `single` — один язык.
2. `subtitled` — основной язык + субтитры на `secondary_languages`.
3. `dubbed` — основной язык + дубляж (голос, при необходимости повторный липсинк) + метаданные на других языках. Поддержка мульти-аудиодорожек на площадке — проверить в API перед реализацией.
4. `mirror_channels` — отдельный канал на каждый язык, серии клонируются с адаптацией.

## Конвейер
- **Script**: по умолчанию сценарий пишется сразу на языке эпизода (native writing), а не переводится. Режим `translate_adapt` — для дубляжа: перевод + культурная адаптация (шутки, примеры, единицы, валюта).
- **Audio**: голос персонажа на каждом языке (TTS или клон с согласием), словарь произношения на канал.
- **Lipsync**: при дубляже в кадре с говорящим лицом — повторный липсинк.
- **Текст в кадре**: шрифты для нужной письменности (кириллица, CJK, арабица/RTL), проверка переносов.
- **Субтитры**: на каждый язык, синхронизация через ASR.
- **Package**: заголовок, описание, теги, главы — отдельно на каждый язык, с учётом поиска на этом рынке.

## Обучение
Golden items, инсайты и эксперименты помечаются языком и рынком. Хук, который сработал на `en`, переносится на `ru` только как гипотеза.

## QA
Определение языка в сценарии, TTS и субтитрах; процент непереведённых фрагментов = 0; проверка произношения имён из словаря; рассинхрон субтитров ≤ 150 мс.

## Онбординг
