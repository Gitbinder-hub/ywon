# ADR 0001: Модульный монолит, contracts-first, Postgres для всего

Статус: принято (v0.1)

## Контекст
Бюджет $200/мес, разработка ИИ-агентами, нужен минимум контекста и инфраструктуры, но готовность к росту и смене моделей.

## Решение
Monorepo, модульный монолит (TS) + Python-воркеры для медиа. Все межмодульные структуры — в packages/contracts. PostgreSQL + pgvector как БД, векторное хранилище и очередь.

## Альтернативы
Микросервисы (дорого, много контекста); Temporal/Redis/векторная БД отдельно (лишние сервисы на старте).

## Последствия
Дёшево и просто. При росте нагрузки очередь и векторы выносятся за те же интерфейсы без изменения домена.
