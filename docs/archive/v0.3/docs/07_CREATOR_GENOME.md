# 07. Creator Genome и Expert Amplifier

Genome — модель человека: цели, экспертиза, ресурсы, вкус, история решений. Тип лица хранится
в presentation канала/серии, не как единственный вид Genome. Один человек может иметь разные серии.
Факты имеют confirmed/inferred/experimental, source, validity и consent/privacy scope.
Предположение о человеке никогда не становится подтверждённым без его выбора.

## Первый запуск — короткий, но честный
Обязательны: тема/аудитория, язык из поддерживаемых, источник знаний/материалов, тип подачи,
доступный голос/согласия, бюджет, ручное review и storage policy. Рекомендации разрешены,
запись выбора требует подтверждения. Нельзя неявно выбрать чужое лицо, клонирование или автопубликацию.
Ниша не зашита, owner проходит обычный UI; unsupported language честно отклоняется.
Пользователь может сразу сделать пилот, затем уточнить стратегию. Прерывание/продолжение обязательны.

## Полный Channel Launch Interview сохранён
Цели → ресурсы → экспертиза → лицо/согласия → аудитория/язык → вкус → площадки →
варианты стратегии → Bible → персонаж/голос → план → контроль → бюджет/хранилище → пилот.
Это progressive modules, не 14 обязательных длинных ступеней до первого полезного результата.
3 стратегии показывают допущения/смету/риски; прогноз роста — сценарий, не обещание.

## Expert Amplifier
Knowledge Extraction: интервью → факты/кейсы/позиция эксперта с provenance и разрешённой областью использования.
Value Check: спрос/новизна — проверяемые гипотезы, не авторитетный вердикт модели о ценности человека.
Packaging: ограниченный формат под ресурсы; claims ground на sources, currentness и фактическую точность.
Coaching: 1–2 конкретных предложения по данным, отдельно от глобального изменения Genome.
Эксперт утверждает смысл до публикации. Медицинский/финансовый/юридический контент требует отдельной policy.

## Метрики
Time to usable export, completion/drop-off, questions count, revisions, human minutes, frustration feedback.
Тестовые персоны проверяют разветвления; настоящие пользователи проверяют UX. UI language ≠ content language.
