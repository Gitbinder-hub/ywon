# 14. Решения владельца и открытые вопросы

## Основание v0.3
01.10.2026 владелец согласился с критическим разбором и поручил переработать пакет,
сохранить все будущие возможности и сделать устойчивую передачу между агентами.
Это разрешение на подготовку пакета, **не подтверждение реальных бюджетов/провайдеров/деплоя**.

## Сохраняем
Массовая модель данных, никаких hidden owner presets; явный выбор языка/лица/бюджета/риска;
собственное ядро/навыки без обязательной зависимости от Higgsfield; сильные доступные модели;
владелец принимает результаты. Продуктовые рекомендации разрешены с прозрачным подтверждением.

## Новые proposed решения к Q-001
R6 staged evidence-first plan; R7 narrated explainer first scope; R8 manual final review initially;
R9 one authoritative task state + generated views + structured handoffs;
R10 future features retained and activated through owner gates;
R11 capability fidelity explicit, no fake free fallback;
R12 reproducibility through retained exact assets, not seed promises.
Статус: предложено в этом пакете, окончательная приёмка через Q-001.

## Не решено (не угадывать)
D01 P0 live-eval cap, валюты, development cap и spend policy.
D02 первая language coverage, поддерживаемые voices, проверочный format/subjects.
D03 real provider IDs/region/terms/official pricing, direct vs aggregator.
D04 supported scaffold/auth library/queue/storage/deploy по ADR.
D05 launch channel/audience/content-language: обычный выбор пользователя, не product hardcode.
D06 target human review time, acceptance rate/cost envelope из Q-003.
D07 publication authorization/API audit path and retention/deletion policy.
D08 next P5 branch by user demand + economics, не simultaneous implementation.
D09 optional English translation after content approval and measured value.

## Шаблон решения
ID/date/owner/question/options/choice/reason/assumptions/affected tasks/features/risk/expiry.
Task registry фиксирует approval, ADR — технический смысл. Не превращать inferred choice в принятое решение.
Поддерживаемый язык и default выбора — разные понятия: config списка языков законен, молчаливый выбор языка канала нет.

>10% alerts, category structure, common Factory core, international UI without browser translator.
