# Companion scenario catalog — восемь гипотез, не гарантии дохода

A-20261005. Requirement anchors SC-01…08; не task state. Runtime/security/contracts: docs/architecture/DESKTOP_COMPANION.md. ResearchIssue/candidate/holdout/canary: EVOLUTION_AND_LAB.md. Все connectors/action scopes активируются отдельно. Обещания «за секунды», «выигрывает отклик», «рутина копейки», цены $50–200 и подписки $5–10 — гипотезы пользователя для эксперимента, не measured performance/pricing.

## Общий контур возможностей
Permissioned connector → source event/provenance/rights/freshness → dedup/conflict check → opportunity hypothesis → bounded sample/analysis → verified artifact → approved external action → measured outcome.
Required reusable contracts: OpportunityRecord(source/time/hash/access/expiry, need, evidence, uncertainty, deadline, rights); ExperimentPlan(hypothesis, falsifiable success, finite attempts/cost/time); ArtifactPackage(input/output lineage, checks, disclosure); ActionProposal(recipient/destination, exact content/version, authority, liabilities); OutcomeObservation(reply/sale/rejection/refund, verified receipts, net costs, unknowns). Contract sketches, не migrations.
API/feed/webhook предпочтительнее polling; polling cadence per source limits and permitted browser access. No access bypass, unbounded crawling or unsolicited mass messaging. Externally sourced text untrusted. Freshness and exact latency measured end-to-end, no second-speed guarantee. Research compute budget separate from execution/customer unit; estimates/paid pending/confirmed kept distinct. Revenue only verified paid receipts after fees/refunds, not lead count or presumed future reward.

## SC-08 wallet boundary
Seed phrases/private keys никогда не попадают в LLM/chat/git/log/ImprovementPackage. First pilot forbids wallet signing/transactions. Later dedicated low-value wallet via external signer; user sees exact network/contract/method/value/fee/allowance and approves independently. Dedicated wallet is not safe by itself. Unlimited approvals/unknown contracts/blockchain purchases require separate risk decision; a website request is not authority. Program scope expiry/change pauses tasks; retaining evidence uses program disclosure policy and minimum data. Bounty scanner cannot discover its own permission.

## Очерёдность и применимость
Первый общий acceptance slice — локальные материалы, без продаж. Затем выбирается ОДИН из SC-01 draft/sample, SC-04 owned-site report, SC-07 lawful small dataset. Selection depends on actual connector/user demand; neither auto-enabled by this doc. SC-02/03/05 need additional data/legal evidence; SC-06 follows demonstrated reusable tool; SC-08 has separate scope/signing gates.
Некоторые monitors entirely cloud-capable; Desktop нужен local-only assets/apps/browser permissions, не обязательная часть каждого заработка. Сценарии требуют tools/data/contracts, а не только промпта «сделай». Общие adapters переиспользуются после compatibility evidence.
Stop: finite experiment budget exhausted, no permission/source rights, stale/unverifiable opportunity, unsafe action, missing binding/deadline or uncertain external outcome. Results may be loss/inconclusive; no forced profitable answer. Outcome tests use genuinely observed clients/sales only separately authorised; synthetic leads/rewards explicitly fixtures.
