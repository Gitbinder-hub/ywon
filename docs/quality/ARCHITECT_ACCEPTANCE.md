# Доказательство работы Архитектора

## Целевые метрики — ещё не достигнуты
Autonomous completion >=90% и admitted-unit pipeline noncompletion/error <=10% — инженерная цель для заранее зафиксированных классов задач. First-generation acceptance, first-delivery acceptance, autonomous completion, critical escaped defects, total/repair cost и human interventions отдельно. «Пользователь увидел одну версию» не first-generation success если внутри пять кандидатов.
Denominator: все units, принятые admission после fixed eligibility; failed/paused/needs_human/cancelled/overbudget/late по preregistered treatment. User cancellation distinguishable, report both all-admitted and policy-defined outcomes without hiding exclusions. Отдельно admission coverage/rejection reasons: нельзя улучшить success rate тайно отсеяв сложные задачи. First generation = initial paid/content candidate per unit/shot as declared, mixed-rollup reported; do not redefine after results.
Repair spend <=accepted R and total <=approved effective cap; original B+R и amendments показаны отдельно. Attempt cost includes rejected jobs/critics/render; local compute unknown не zero. Time не reserve basis, но latency/deadlines/intervention minutes остаются operational metrics.

## Quality gates
Hard checks: schema/rights/required claims/format/duration/audio/title/safe areas. Multimodal: identity/product/camera/semantic/continuity with calibrated methods; critic advisory. Human preference: blind rubric and human labels. Critical failure blocks result regardless average score. Verify automated judge false-pass/false-fail against labeled data, correlation of models, full-video/transitions/time sample coverage.
Golden cases immutable/versioned; separate holdout not tuned; represent declared task classes, complexity/language/route. Register sample/CI method/thresholds BEFORE real runs; minimum n/statistical confidence decided Q-003, not invented success from small pilot. No fixed universal metric proves professional quality.

## Mandatory failure/economic scenarios
Crash before submit / after submit before external id persist; webhook replay; idempotency unsupported; lost poll response; reservation races; same-click duplicates; exhausted unit/project/month budget; exactly cap and +minor unit; unknown invoice/cancel; third attempt denied with money remaining; manual edit invalidates approval; changed route unsupported inputs; revoked rights publish blocked; malicious repository text; wrong tenant/private-memory access; external new model adoption denied; missing measurement uncertain; affected-only DAG repair; protected code/tests mutation denied.
Models can be mocked for mechanical/security tests. Real media/cost proof only separately funded live eval; subjective quality and ordinary-user usability require actual human/novice evidence. Offline contract checker is NOT runtime/protected ledger proof.

## Activation
P1 foundation invariant/failure tests; P2 manual real workflow; P3 delegated-mode pilot via scoped owner gate after real repeatability/recovery/judge evidence. Can run nonpublishing/shadow comparison first with explicit privacy/cost scope. Human-sampled interventions counted. Automated publish separately authorized official API/destination/time/version and rights. Stop criteria and rollback/revocation tested before activation. Public promise tied supported class/rubric/liability/remedy, not absolute viral/market guarantee.
