# Текст, посты, карусели и Stories

## P2 minimum
Structured content blocks: title/body/CTA/caption; text selection edits (shorter/clearer/softer/author voice).
AI action изменяет только выбранные blocks в новой версии; show diff + accept/reject, delta estimate.
Manual text changes не требуют платной LLM. Autosave/undo/version compare; locked/approved wording.
Knowledge refs/claim status, critical unsupported claims блокируют финал по policy.
Channel style из confirmed facts, пользователь может выключить/изменить, не невидимый prompt.
Platform constraints (count/format/metadata) pinned и показываются; native preview — approximate,
не обещание pixel-identical отображения всеми версиями внешнего приложения.

## P5 sequence scope
Carousel: ordered slide documents + shared theme; reorder/add/remove, per-slide overlay editor,
continuity/overflow/font/safe-area QA, export package с порядок/caption metadata.
Stories: sequence items image/video/text, duration per item, coherent CTA, platform-specific boundaries.
Interactive stickers остаются отдельной unsupported/API-capability проблемой, не просто raster overlay.
Post→Carousel/Story/Script создаёт linked derivative, сохраняет sources и отмечает semantic adaptation.
Перевод чужих/рисковых утверждений не превращает их в подтверждённые.

## AC
RU/EN basic editing/reload/export; long text overflow, multi-byte char count rule,
IME, unicode/bidi sanitization, markdown/rich-text safe paste; font/glyph и RTL layout tests при запуске языка.
Text source и on-screen typography связаны явно, изменение одного не портит принятый другой без diff.
Sequence export требует QA всех items, не только обложки.
