# Миграции — простыми словами
- 001 привязывает каждую запись к workspace (забор между клиентами)
- Порядок применения — по номеру файла; обратная миграция (down) — удалить таблицы в обратном порядке
- Запуск только в транзакции, без тяжёлых блокировок
- Бэкап/restore — pg_dump до миграции и проверка что бэкап читается
